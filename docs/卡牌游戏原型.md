# 卡牌游戏方案

## 1、游戏规则

### （1）卡牌类型概述

游戏中共会出现3种卡：角色卡、能量卡和特殊卡。角色卡有初始血量、技能两个信息。能量卡分1能量、2能量、3能量和万能能量这4种。特殊卡不提供能量，使用它等效于发动一次技能效果。能量卡和特殊卡共同组成卡组，卡组是所有玩家抽卡的来源。当开局的初始卡组抽空后，会立刻洗切弃牌区卡牌，作为新的卡组供玩家抽卡。

### （2）开局流程

开局：每个人开局可以选一张角色卡；然后确定某一个玩家为1号位，由ta开始根据玩家的位置延顺时针方向依次确定玩家编号，根据编号顺序，每个玩家各自从卡组中抽4张卡，抽出的卡称为该玩家的手卡；抽完卡后，n号位置的玩家有n-1次（最大为4）将手卡中的一张卡放回卡组底部，然后重新抽卡的机会，这个过程称为"换卡"。在所有玩家的换卡结束后，重新洗切卡组，开局结束。

### （3）回合流程

开局结束后进入回合1，回合数不断递增直到决出胜者。每一回合分为三个阶段。

**阶段1**：游戏的所有参与者从手卡中，选择将若干张卡背面朝下放置在角色卡旁，当所有玩家放好后，同时揭开；计算每个玩家揭开的所有卡片的总能量数，万能能量卡和特殊卡记作1点能量，能量数越大则玩家在本回合内越先行动，能量数相同则根据编号从小到大的顺序行动；在确定行动顺序后，放置过的能量卡加入弃牌区。

**阶段2**：玩家按照行动顺序行动，除了第一回合，玩家的行动开始可以从卡组摸两张卡，然后释放角色卡中的技能、使用特殊卡或者宣言结束行动；技能由能量消耗与效果组成，能量消耗是技能的发动条件。若手卡中的能量卡上的能量大于等于技能的能量消耗，则可将该能量卡置入弃牌区，然后发动技能的效果，也可以同时使用多张能量卡满足同一次技能的能量消耗条件，万能能量卡在作为技能的条件时，可以作为1到6中任意一种能量数使用。一回合内若技能本身无规定，则可以无次数限制的使用技能，直到所有手卡耗尽。

**阶段3**：所有玩家均行动结束后，结算生效中的印记效果。印记效果分为正面和负面两类，会影响玩家的当前血量以及下一回合的行动情况；同名印记最多存在1个，且重新附加印记时，以最新的印记的持续时间作为持续的时间；在印记发生覆盖时，对于正面印记，旧印记每剩下1回合则会让玩家立刻获得2点护盾，对于负面印记，旧印记每剩下1回合则会让玩家立刻受到2点穿透。

### （4）血战机制

血战：当回合数大于20时，进入"血战"期，所有玩家在阶段3印记效果结算完后，都受到20点穿透。

### （5）胜利条件

胜利条件：技能与特殊卡的效果可以改变其他玩家的血量，当玩家的血量归0，则该玩家判为失败，坚持到最后的玩家为胜利者。

### （6）专有名词定义

游戏中的其他专有名词：

- **伤害**：令指定玩家的当前血量扣除，最小值为0。
- **回复**：令指定玩家的当前血量回复，最小值为0，当玩家的当前血量最大值为初始血量，溢出回复不计算。
- **护盾**：当护盾存在时，可以抵消伤害直到护盾值归0，最小值为0。
- **穿透**：令指定玩家的当前血量扣除，无视护盾的抵挡作用，最小值为0。（增加伤害的效果无法增加穿透）

## 2、卡牌设计

### （1）角色卡

#### 【角色卡1-平衡】

- **初始血量**：100
- **技能1**：能量消耗1，效果：指定一位其他玩家，使其受到3点伤害
- **技能2**：能量消耗2，效果：回复自己4点血量
- **技能3**：能量消耗3，效果：为自己附加"无垢"和"灵感"印记2回合
- **技能4**：能量消耗4，效果：指定一位其他玩家，使其受到8点伤害和4点穿透，然后自己从卡组中抽1张卡

#### 【角色卡2-防御】

- **初始血量**：135
- **技能1**：能量消耗1，效果：指定一位其他玩家，使其受到1点伤害，然后自己获得2点护盾
- **技能2**：能量消耗2，效果：自己获得6点护盾
- **技能3**：能量消耗2，效果：为自己附加"庇佑"印记3回合
- **技能4**：能量消耗6，效果：指定一位其他玩家，使其受到12点伤害，然后自己回复当前护盾数值一半（向下取整）的血量，若指定的玩家手牌小于等于2，则使其受到12点穿透

#### 【角色卡3-进攻】

- **初始血量**：80
- **技能1**：能量消耗1，效果：指定一位其他玩家，使其受到3点伤害
- **技能2**：能量消耗2，效果：指定一位其他玩家，使其受到4点伤害和2点穿透
- **技能3**：能量消耗3，效果：指定一位其他玩家，使其受到6点伤害，然后自己从卡组中抽1张卡
- **技能4**：能量消耗6，效果：指定一位其他玩家，使其受到12点伤害和6点穿透，然后若指定的玩家当前血量大于自己当前血量，则再使其受到18点穿透

#### 【角色卡4-强化】

- **初始血量**：110
- **技能1**：能量消耗1，效果：指定一位其他玩家，使其受到1点伤害，然后自己下一回合所有伤害增加3
- **技能2**：能量消耗1，效果：指定一位其他玩家，使其受到0点伤害，回复自己0点血量，然后自己下一回合所有回复增加2
- **技能3**：能量消耗3，效果：指定一位其他玩家，使其受到3点伤害，回复自己3点血量，然后自己下一回合所有伤害增加3，所有回复增加3
- **技能4**：能量消耗6，效果：指定一位其他玩家，使其受到0点伤害，然后自己下一回合所有伤害增加6，并从卡组中抽1张卡

#### 【角色卡5-先手】

- **初始血量**：90
- **技能1**：能量消耗1，效果：指定一位其他玩家，使其受到2点伤害，然后若该玩家还未行动则使其再受到2点伤害
- **技能2**：能量消耗2，效果：指定一位其他玩家，使其受到2点伤害，然后若该玩家还未行动，则自己从卡组中抽1张卡，同一回合内此技能最多使用3次
- **技能3**：能量消耗3，效果：指定一位其他玩家，使其受到3点伤害和3点穿透，然后若该玩家还未行动，则为自己附加"鼓舞"、"灵感"和"流血"印记各1回合
- **技能4**：能量消耗6，效果：指定一位其他玩家，附加"失明"印记1回合，然后若该玩家已经行动，则额外附加"睡眠"印记1回合，且自己下一回合所有伤害增加2

#### 【角色卡6-持久】

- **初始血量**：115
- **技能1**：能量消耗1，效果：指定一位其他玩家，使其受到1点穿透，然后回复自己2点血量
- **技能2**：能量消耗2，效果：指定一位其他玩家，附加"中毒"印记1回合，然后回复自己2点血量，若该玩家已拥有"中毒"印记，则使其受到3点穿透
- **技能3**：能量消耗3，效果：指定一位其他玩家，附加"诅咒"印记3回合，然后为自己附加"治疗"印记3回合
- **技能4**：能量消耗6，效果：指定一位其他玩家，附加"流血"印记3回合，然后当回合数大于12时，使指定的玩家受到当前回合数一半加6的穿透，并回复自己当前回合数一半的血量

#### 【角色卡7-弱化】

- **初始血量**：80
- **技能1**：能量消耗1，效果：指定一位其他玩家，使其受到2点伤害并附加"弱化"印记1回合
- **技能2**：能量消耗2，效果：指定一位其他玩家，若其没有"弱化"印记则附加"弱化"印记2回合；若其已有"弱化"印记，则为自己附加"治疗"印记2回合
- **技能3**：能量消耗3，效果：指定一位其他玩家，若其没有"弱化"印记则附加"弱化"印记2回合；若其已有"弱化"印记，则附加"失明"和"失神"印记1回合
- **技能4**：能量消耗6，效果：指定一位其他玩家，使其受到6点伤害，若当前回合数大于8，则使该玩家受到弱化角色当前血量十分之一（向下取整）的伤害和穿透

#### 【角色卡8-反击】

- **初始血量**：105
- **技能1**：能量消耗1，效果：指定一位其他玩家，使其受到2点伤害，然后若本回合自己受到过伤害，则使其再受到2点伤害
- **技能2**：能量消耗2，效果：指定一位其他玩家，使其受到4点伤害，然后若本回合自己受到过伤害，则回复自己4点血量
- **技能3**：能量消耗3，效果：指定一位其他玩家，使其受到6点伤害，然后若本回合自己受到过伤害，则令指定的玩家附加"诅咒"印记1回合
- **技能4**：能量消耗6，效果：指定一位其他玩家，使其受到6点伤害和6点穿透，然后若本回合自己未受到过伤害，则令自己和指定的玩家受到4点伤害

#### 【角色卡9-连击】

- **初始血量**：90
- **技能1**：能量消耗1，效果：指定一位其他玩家，使其受到2点伤害和1点穿透
- **技能2**：能量消耗2，效果：自己下一回合所有伤害增加2，所有穿透增加2，所有回复增加1
- **技能3**：能量消耗2，效果：指定一位其他玩家，使其受到0点伤害，然后回复自己0点血量并从卡组中抽1张卡
- **技能4**：能量消耗6，效果：指定一位其他玩家，使其受到本回合自己已经使用技能的次数2倍的穿透，然后若本回合自己使用技能的次数小于等于3，则为自己附加"无垢"和"灵感"印记1回合

### （2）能量卡

- **1能量卡**：出现概率40%
- **2能量卡**：出现概率30%
- **3能量卡**：出现概率15%
- **万能能量卡**：出现概率5%
- **特殊卡**：总共出现概率10%（每种特效卡出现的概率相同）
