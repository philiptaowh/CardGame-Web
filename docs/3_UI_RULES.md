# 3_UI_RULES.md: UI与设计规范

## 1. 核心准则 (UI Principles)
- **极简主义**：界面干净，留白充足，深色主题营造沉浸式桌游氛围
- **响应式优先**：默认适配桌面端，后期可扩展移动端
- **测试友好 (Testability)**：【建议】关键交互元素可添加 `data-testid` 属性，便于自动化测试
- **动态适配**：组件基于游戏状态动态渲染，禁止硬编码列表

## 2. 页面布局极简准则 (AI 必须遵守)
1. **别让内容撑满屏幕**：所有页面的最外层容器，必须限制最大宽度，让内容乖乖呆在屏幕中间，两边留白。
2. **凡是列表必加间距**：只要用 `flex` 竖着排或者横着排组件，必须加上 `gap-4` 或 `space-y-4`，绝对不允许两个组件肉贴肉挨在一起。
3. **卡片标配样式**：所有的表单和核心内容，必须用独立卡片包起来。

## 3. 颜色与视觉 (Visuals)
- **主色调**: `indigo-600`（按钮/高亮）
- **背景**: `slate-900` → `slate-800`（渐变）
- **玩家区域**: `indigo-900/50`（当前玩家高亮边框）
- **对手区域**: `slate-800/30`
- **能量卡**: `yellow-900/50`（黄）
- **特殊卡**: `red-900/50`（红）
- **万能能量**: `purple-400`（紫）
- **状态颜色**: 成功 (green), 危险 (red), 警告 (yellow), 护盾 (blue)

## 4. 交互与状态感知 (State Feedback)
- **加载态**：AI思考时显示"AI 思考中..."动画
- **禁用态**：能量不足时技能按钮灰显 `disabled:opacity-50`
- **悬停态**：按钮定义 `hover:bg-xxx` 和 `transition-colors`
- **选中态**：卡片边缘发光效果

## 5. 日志系统 (Game Log)
- 位置：页面右侧中央
- 功能：记录游戏事件（抽卡/技能/伤害/印记结算）
- 交互：折叠/展开按钮

## 6. 组件编写信条 (Component Rules)
- 使用 Tailwind CSS 工具类，禁止手写 CSS
- 保持组件单一职责
- 逻辑复杂的组件拆分为独立文件（如 SkillPaymentModal）
- 深色主题优先，确保文字对比度

## 7. 图标规范
- 图标库：统一使用 `lucide-react`
- 常用图标：Heart (HP), Shield (护盾), Zap (能量), Hand (手牌)
