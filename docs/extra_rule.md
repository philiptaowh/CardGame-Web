# 游戏设计补充裁定 (Extra Rules)

## 1. 角色5（先手）"已行动"判定标准

### 1.1 问题背景

角色5（先手）的技能效果中有条件判断"若该玩家还未行动"或"若该玩家已经行动"（即 `has_acted_this_turn`）。在多人模式下，需要明确定义"已行动"的边界。

### 1.2 裁定结果

**核心规则**：`has_acted_this_turn` 在当前玩家退出阶段2时自动标记为 `true`。

触发时机：
- 玩家使用技能/特殊卡 → `useSkill`/`useSpecialCard` 执行时直接设 `true`
- 玩家主动点击"结束行动" → `advancePhase` 切换到下一玩家时设 `true`
- 玩家被睡眠跳过 → **不标记**（该玩家从未获得行动机会）

### 1.3 行为对照表

| 场景 | has_acted_this_turn | 先手技能1-3是否触发加成 |
|------|---------------------|------------------------|
| 对手使用过技能 | `true` | 否 |
| 对手主动结束行动（未用技能） | `true` | 否 |
| 对手还没轮到行动 | `false` | 是 |
| 对手被睡眠跳过 | `false` | 是 |
| 对手被失神/混乱影响但使用了技能 | `true` | 否 |

### 1.4 设计意图

"先手"的定位是"在对象出手前触发特殊效果"，而非"在所有人之前"。只要目标玩家在本回合没有做出过任何行动决策（使用技能/特殊卡），角色5即可触发加成效果。

---

## 2. 玩家行动状态框架

### 2.1 模型定义

使用 `has_acted_this_turn: boolean` 区分两类状态：

```
未行动(false) ─┬─ 还没轮到（被行动顺序覆盖）
               └─ 轮到但被跳过（睡眠等状态影响）
已行动(true)  ─┬─ 使用了技能/特殊卡
               └─ 轮到且主动结束行动（pass）
```

### 2.2 状态流转

```
endTurn → has_acted = false (重置)
  │
  ├─ phase2 轮到该玩家
  │    ├─ 使用技能 → has_acted = true
  │    ├─ 使用特殊卡 → has_acted = true
  │    ├─ 结束行动（advancePhase） → has_acted = true
  │    └─ 睡眠跳过（advancePhase自动检测） → has_acted = false
  │
  └─ endTurn（下一回合重置）
```

### 2.3 未来可扩展性

若后续角色需要更精细地判断玩家状态（区分"未轮到"和"被跳过"），可将 `boolean` 升级为枚举：

```typescript
// 未来扩展方案（当前未采用）
turn_action_state: 'not_reached' | 'passed' | 'acted' | 'skipped_by_sleep'
```

当前 `boolean` 方案足够覆盖所有角色的 PRD 需求，升级枚举不会影响已有逻辑。

## 3. 适用范围

- **适用角色**：角色5（先手）
- **适用版本**：v1.0.1+
- **不适用**：被动效果（如印记结算、反击标记 `took_damage_this_turn`）
