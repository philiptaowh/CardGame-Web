# 卡牌游戏 (Card Game)

一款基于浏览器的回合制卡牌对战游戏。

---

## 技术框架

### 核心技术栈

| 类别 | 技术 | 版本要求 |
|------|------|----------|
| **前端框架** | React | 19.x |
| **编程语言** | TypeScript | ~6.0 |
| **构建工具** | Vite | 8.x |
| **状态管理** | Zustand | 5.x |
| **UI样式** | Tailwind CSS | 4.x |
| **后端通信** | WebSocket (ws) | 8.x |
| **桌面壳** | Electron | 35.x |
| **测试框架** | Vitest | 3.x |

### 环境要求

| 软件 | 最低版本 | 推荐版本 |
|------|----------|----------|
| **Node.js** | 20.x LTS | 20.x LTS |
| **npm** | 10.x | 与Node.js捆绑 |

**不支持**：Node.js 18及以下、奇数版本（19/21）

## 开发模式

### 安装

```bash
# 进入项目目录
cd card-game

# 安装依赖
npm install
```

### 启动开发服务器

```bash
npm run dev
```

然后打开浏览器访问 **http://localhost:5173**

### 开发命令

| 命令 | 说明 |
|------|------|
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 编译生产版本 |
| `npm run test` | 运行测试 |
| `npm run lint` | 代码检查 |

## 游玩模式（打包为EXE）

### 打包

```bash
cd card-game
npm run pack
```

### 运行

打包完成后，EXE文件位于 `card-game/release/` 目录，直接双击运行。

## 游戏界面操作说明

### 主菜单

| 选项 | 说明 |
|------|------|
| **单人练习** | 与AI对战 |
| **创建房间** | 作为主机创建局域网房间 |
| **加入房间** | 输入房间号加入游戏 |

⚠️ **如果对于游戏规则、角色技能效果、特殊卡牌效果有任何不清楚的地方，可以在游戏内右下角的「帮助」按钮中查看所有游戏信息**

### 角色选择

游戏提供9种角色，每种有4个独特技能：

| 角色 | 定位 | HP | 特点 |
|------|------|-----|------|
| 平衡 | 平衡型 | 100 | 综合能力强 |
| 防御 | 防御型 | 135 | 高生命，高护盾 |
| 进攻 | 攻击型 | 80 | 高输出伤害 |
| 强化 | 增益型 | 110 | 强化队友 |
| 先手 | 先攻型 | 90 | 抢佔先手 |
| 持久 | 持久型 | 115 | 持续伤害 |
| 弱化 | 弱化型 | 80 | 降低敌人 |
| 反击 | 反击型 | 105 | 受击反弹 |
| 连击 | 连击型 | 90 | 多次攻击 |

### 游戏流程

游戏分为3个阶段循环进行：

#### 阶段1：能量放置
- 从手牌中选择能量卡放置
- 能量卡决定本回合行动顺序
- 点击卡牌 → 点击「确认能量」

#### 阶段2：技能行动
- 使用角色技能或特殊卡牌
- 选择目标玩家
- 点击「结束行动」

#### 阶段3：印记结算
- 自动结算所有印记效果
- 抽2张新卡

### 操作按钮

| 按钮 | 功能 |
|------|------|
| **确认能量** | 确认能量放置 |
| **结束行动** | 结束技能行动 |
| **发起投降** | 认输 |
| **再来一局** | 重新开始 |

### 界面布局

- **左上角**：回合数、当前阶段
- **右上角**：时间银行（联机模式）
- **上方**：所有玩家状态条
- **中央**：游戏桌面对战区域
- **下方**：手牌区
